# AstrBot See Now Implementation Plan

**Goal:** Provide a separate AstrBot plugin for analyzing video files with the upstream dsh-see-now frame selection pipeline.

**Architecture:** A Node subprocess uses the upstream capture and pipeline exports, writes ordered contact sheets and metadata to an isolated directory, and a Python AstrBot entry point submits bounded batches to the configured vision provider. Keep explicit invocation so existing video handling and privacy rules are not silently bypassed.

**Validation:** Test failed and successful extraction, queue draining and cleanup, boundaries and errors; exercise FFmpeg with synthetic video; test AstrBot request handling without sending private media. Verify attribution and upstream noncommercial license. Compare actual quality and costs separately before replacing existing handling.

1. Implement and test the bounded offline extraction bridge, retaining upstream algorithm and attribution.
2. Implement and test AstrBot interface, output batching, cleanup, and failure reporting.
3. Document prerequisites, limitations, licensing and installation. Verify as a whole and check publishing access.
